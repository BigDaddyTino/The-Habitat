# Rive sample asset notice

`habitat-vista-control.riv` is the `rating_animation.riv` runtime example from
the [rive-app/rive-wasm](https://github.com/rive-app/rive-wasm) repository.
It is redistributed under that repository's MIT license and is used as the
interactive Rive state-machine layer in the Great Hall vista control.

The surrounding field-glass presentation, Three.js scene, timing, interaction,
and accessibility behavior are original Habitat implementation work.
