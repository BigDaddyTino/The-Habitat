# SOL 5.6 Trainer Portrait Ledger

Date: 2026-08-31

## Scope and publication state

This run created the fourteen depictable trainer subjects from the standing class-constellation visual table. The Crossroads bargain and the hidden Concordance elder were deliberately not depicted.

NAG already has a canonical `CHARACTER` record and resolves through the authenticated Codex art route. The other thirteen dossiers have not been authored yet. Their images are therefore dormant convention-path assets only; this ledger does not treat the visual staging, faces, clothing details, props, or backgrounds as new canon.

Generation used the built-in ImageGen path, with one generation call per distinct asset. Marta Voss established the batch anchor. Existing Habitat images were supplied only as style, material, crop, or anatomy references and never as identity references.
