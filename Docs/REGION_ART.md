# Codex Region and POI Art

The Codex has an original cinematic environment painting for every canonical region and point of interest. The production registry is [`apps/web/lib/region-branding.ts`](../apps/web/lib/region-branding.ts); its test requires all 14 files to be 1600 × 900 JPEGs.

## Shared art direction

All images were made with Codex's built-in image generation mode using this shared direction:

> Stylized-concept AAA game environment key art, photorealistic cinematic 16:9 composition, modern-day to near-future dark fantasy, richly detailed PBR materials, believable practical infrastructure, responsive crop with the main landmarks near center, restrained supernatural light integrated into contemporary technology. Mature 17+ atmosphere without explicit gore. No medieval castle, knight, heraldry, sword-and-sorcery costume, text, lettering, logo, UI, watermark, or named character.
